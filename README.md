# Rotation Studio class guides

Class guides that Rotation Studio downloads and keeps up to date on each user's PC.
They're laid out as `<patch>/<class>/<spec>.md` or `<patch>/<specID>.md`.
WoW Forever guides are in `forever/<class>.md`, one per class (Forever has no specs).

The guides summarize public sources, mainly Icy Veins and Wowhead (Forever: wowtbc.gg and Maxroll). Simia's stock YAML is still the APL.
